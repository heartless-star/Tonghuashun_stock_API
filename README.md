# 同花顺行情数据采集

基于同花顺公开API的A股实时行情数据采集工具。

## 使用方法

### 环境要求

- Python 3.6+
- `requests` 库

```bash
pip install requests
```

### 运行

```bash
python tonhuashun.py
```

### 自定义查询股票

修改 `json_data` 中的 `codes` 和 `market`：

```python
json_data = {
    'code_list': [
        {
            'codes': ['000001', '600519'],  # 股票代码
            'market': '33',                  # 市场代码 33=深市 1=沪市
        },
    ],
    'trade_class': 'post_market',   # 行情模式
    ...
}
```

## 注意事项

1. **接口权限** — 请求头中的 `x-fuyao-auth` token 有有效期，过期需更新
2. **字段代码** — 请求的 `data_fields` 顺序与返回的 `data_fields` 顺序**不一致**，返回的是按字段代码排序的
3. **字段重复** — `昨收` 有两个字段代码(11和6)，其中字段11在部分模式下返回null，建议优先使用字段6
4. **涨跌额 vs 涨跌幅** — 字段264648是**涨跌额**(价格差)，字段199112才是**涨跌幅**(百分比)，注意区分
5. **大数格式化** — 流通市值/总市值等大数值默认保留2位小数
6. **行情模式** — `trade_class` 支持 `post_market`(盘后)、`pre_market`(盘前) 等模式
